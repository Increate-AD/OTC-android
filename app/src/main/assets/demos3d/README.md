The 3D demo videos are generated by the GitHub Actions workflow
`.github/workflows/render-3d-demos.yml`. They use a consistent MPFB2 / MakeHuman
male muscular base model and the selected CC0 motion/keyframe sources from
OpenGym3D. MP4 files are bundled in the APK for offline playback.

Not every OTC exercise has a movement-matched 3D clip yet. The app only selects
a 3D clip for exercises with an explicitly mapped match; other exercises retain
their existing fallback until a correct animation is available.

Attribution and license notes are in ATTRIBUTION.txt.
